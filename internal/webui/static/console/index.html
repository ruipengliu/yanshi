yanshi 调试控制台 通话页

EndUser

令牌：yanshi token -key demo.key -user <用户>。网关以令牌中的身份为准。

设备

手机与电脑是 Node（声明 Capability、执行调用），同时作会话客户端；网页只作会话客户端。

Session

演示

Agent console 按命令行事：call <工具> {JSON} 调用能力（工具名为 <设备标签>__<能力>，可多行依次调用），ask 问题 | 选项 | 选项 提问， stream 200 长输出（插话、中断、晚加入）；其余输入原样复述。每台设备的输入框下有命令模板。

没有打开的 Session：新建一个，或在左侧输入 ID 后打开。
