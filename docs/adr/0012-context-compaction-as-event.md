# 上下文压缩记录为 Event

Session 历史超出模型上下文窗口时，由 Worker 调用模型生成摘要，并把摘要连同截断位置（`through_seq`）作为 `ContextCompacted` 事件追加到日志。之后组装模型上下文时，使用"最新摘要 + 其后的历史"。我们没有选择"每次组装上下文时临时截断或临时摘要"：截断会丢失早期的目标和副作用记录；临时摘要的结果不确定，接管者、回放和评测会看到不同的上下文，违反 ADR-0004。

## Consequences

- 原始事件从不删除，只是不再出现在模型上下文中。审计、回放和客户端展示都不受影响。
- 摘要生成受 Attempt fencing 约束，被中断或接管时作废，不会提交。
- 截断位置必须是闭合边界（此前请求的调用都已有结果），由 `session.Reduce` 校验。
- 摘要质量直接影响长任务的正确性，尤其是"哪些副作用已经发生"。因此摘要指令属于需要评测回归的内容（章程原则 10）。
