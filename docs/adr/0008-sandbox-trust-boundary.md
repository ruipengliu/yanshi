# 沙箱内不放任何受信组件：由沙箱外的控制器作为 Node

云端 Sandbox 以"受信控制器 + 不可信执行环境"的方式接入：沙箱控制器运行在沙箱之外，作为 Node 从 Inbox 领取调用，再经容器运行时把命令送入沙箱执行；沙箱内只有用户与模型的代码，不持有任何凭证，也不连接平台。我们没有选择"在沙箱内运行 SDK 连回网关"，因为模型生成的代码不可信，与持有凭证的组件同处一个环境就可能冒充 Node 或伪造结果。

## Consequences

- 沙箱复用 M1 的全部机制（路由、Inbox、call_id 去重、挂起、超时、中断）；去重账本由控制器持久化在共享存储中，任何控制器实例都能接管。
- 沙箱默认无网络，连回平台的通路根本不存在。
