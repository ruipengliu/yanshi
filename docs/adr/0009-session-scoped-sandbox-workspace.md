# 每个 Session 一个沙箱工作区

沙箱按 Session 划分：首次调用时创建，同一 Session 的所有 Run 共享工作区文件系统（`/workspace`），空闲超时后回收计算资源而保留工作区，下次调用时恢复。这样"下载数据 → 分析 → 出图"可以跨多步、跨多个 Run，并在挂起数小时后继续；没有选择"每次调用一个干净环境"（无法多步协作）或"每个 EndUser 一个"（跨 Session 互相污染、隔离与清理粒度过粗）。

## Consequences

- 同一沙箱内的调用串行执行（由沙箱租约保证）。
- 工作区的持久化方式随实现而变：开发用 Docker 命名卷，生产（ADR-0010）用持久卷或快照。
