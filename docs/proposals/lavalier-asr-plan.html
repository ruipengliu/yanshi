机主全天佩戴，录音经手机批量上云。方案要回答三件事：哪些声音不该进转写和记忆，转写准不准（尤其专名），以及每句话是不是机主说的。原则是宁可漏记，不可错记。

§0结论

批处理链路领夹 → 手机暂存 → 按批上云 → 异步处理 → 回传 App。两级队列：常规 P90 ≤3 小时，“立即同步”上传后 P90 ≤10 分钟目标。
四级拒识级联越靠前越便宜，也越保守。设备和手机只丢非语音，像人声的一律上云。播放检测只打标签，二期“跳过识别”为可选、默认关。
三档处置拒绝只用于非语音和无语音帧的幻觉；播放声、疑似回放、幻觉型分歧隔离 7 天，可放回。说话人不确定不隔离，记为“未知说话人”接受。写入纪要、待办、记忆另按身份、文字、相关性、语义支持四维核验。
8B 单路全量600M 只做对齐、全量声学支持评分与可疑片段校验。级联路由每人每月只省约 ¥3估算。
三类热词解码前按上下文检索出偏置表，只解码一次；解码后按拼音、音素召回，再做可弃权的闭集纠错。个人热词不从纪要回收。
机主判定一期以声纹为主，近场特征作为模型输入，删音频前做批内重聚类；二期加 VPU 融合。VPU 分不清电视和在场的真人。记忆与待办只引用“证据级”原话，且要过四维核验。
按对话单元出纪要日历会议、10 分钟静默或参与者换了一批时切出单元；没有机主参与的单元不出纪要；相关性判定为背景的人（邻座闲聊、漏网的电视台词）不作纪要上下文、不支撑待办。待办按承担人分四类。迟到数据、续说和用户改字、改标都会重开单元、更新纪要。
约 ¥25/人/月按需求口径每天 5 小时有效音频（约 20 小时佩戴，属高位）、8B ¥0.10/小时估算，落在 ¥23–27 内。典型佩戴 12 小时约 3 小时有效，约 ¥15。
音频在 G5 后即删识别结果落盘就删音频，领夹在手机回执后即擦除，之后只读文字；他人只留簇质心，业务日结束后 12 小时删除。代价是不能事后重跑；低置信区间保留文字候选。

五条设计原则

  1. 不可逆操作最保守：丢音频、不送识别、改写文字，证据充分才做。
  2. 越靠前越便宜，但越靠前越不许误杀人声。
  3. 处置只收紧不放宽；只有用户操作可以升级，且每种操作只确认一个维度（§5.10）。
  4. 宁可漏记，不可错记；说不准是谁说的就记为“未知说话人”，不归到任何人名下。
  5. 每一级都能单独开关，与“不做”配对评测。

§3硬件（领夹）

  • 缺口不压缩时间轴；开启 DTX 时只按帧序号推算时间。
  • 原样保存设备码流，L1 只解一份临时 PCM。

时钟校准

  • 同步点：每次连接 + 连接中每 5 分钟。
  • 线性拟合 offset、drift_ppm；日漂移 ≤1.7 s估算。
  • 异常：重启（世代变化）、手动改时间、拟合残差过大 → 分段重拟合，标 sync_quality_ms。
  • 录音时刻还原误差 ≤200 ms目标。

L1 拒识

  • 只丢：VAD 高置信非语音，前后各留 500 ms 后仍为非语音；间隔 <2 s 的语音段合并。
  • 不做声音事件分类：云端的 CPU 小模型已包含；本机外放由场景事件记录。
  • 运行时机：BLE 收到数据后增量运行，每个 5 分钟分片约数秒 CPU估算，不依赖系统择机执行的后台任务。
  • 一期是第一道丢弃闸：留出前后余量后，约丢掉 65% 的佩戴时长，每佩戴 1 小时上传约 0.35 小时假设；二期只复核。

5.6 机主判定

流程

  1. 判定单位是说话人轮次：按换人点切分，再用 600M 的 CTC 对齐把字分到各轮次；一个识别分片可以包含多个轮次。
  2. 当天在线聚类（CAM++ / ERes2NetV2 一类）：只保留各簇质心与计数，新轮次归入已有簇或新建；逐轮次嵌入在批内重聚类后、G5 检查点删除（2 / 6 小时缓存是一期变体，§5.10）。簇号只在业务日内有效，质心在业务日结束后再留 12 小时供迟到分片使用，更晚到达的分片单独聚类、簇号标“迟到”。
  3. 轮次级得分 + 簇级得分（簇累计 ≥10 s 语音后）。
  4. <1.5 s 短轮次：结合簇得分、离簇中心距离、前后长轮次与帧级证据判断，不因紧邻他人就自动记为未知；仍拿不准的记为未知说话人。
  5. 只有实际重叠和边界模糊的区间记为未知说话人，不扩大到整段。
  6. 近场特征（相对声级、直达/混响比）作为模型输入，不能单独授予机主。
  7. 簇名：单元关闭时，LLM 按称呼线索（“小王你……”）和该会议时段的个人热词（日历参会人）给他人簇建议名字，用户确认后才显示。名字只在业务日内有效，不跨天关联，不形成他人身份档案。

证据级 ≠ 时间线级

证据级条件：声纹 ≥T_evidence（高于 T_high）；二期还要求 VPU 有效且有发声；不在重叠或邻近重叠处；片段 ≥1 s。

理由估算：他人每天可能说 2–3 小时，1% 误判就是每天 1–2 分钟被标成机主，足以每周产生数条错误的“我答应的”待办。

阈值只在调参集选定；T_high、T_evidence 按误判上限定，不随召回放宽；T_low 按召回定。

识别作业的状态

  1. queued：拼接器生成，带队列类别与截止时间。作业 ID = 用户 + 设备 + 启动世代 + 帧序号区间 + 管线版本的哈希，重复生成即同一作业。
  2. running：领取时写入租约与过期时间；租约过期由别的进程接手，从音频重跑。
  3. persisted：① 完成。此后不再重跑，片段 ID = 作业 ID + 轮次序号，保持稳定。
  4. audio_deleted → receipted：② ③ 完成。
  5. 失败：按退避重试；永久失败满 48 小时，删除音频、登记缺口（cloud_failed）并回执，App 显示该时段识别失败。

崩溃点与恢复

  • ① 之前：事务未提交，簇质心也未更新；作业从音频重跑。
  • ① 与 ② 之间：巡检找出全部帧已落盘、对象仍在的分片，补删。
  • ② 与 ③ 之间：巡检确认对象不存在，补记并补发回执。
  • 回执丢失：手机按游标拉取，回执可重复；手机重复上传已删除的分片时，网关按 chunk_id 直接返回“已删除”，不再收音频。
  • 文字段失败：只推迟可见，不影响删除链；按片段重试。
规则内容
识别分片在 ≥300 ms 的停顿处切，目标 15–45 秒估算（与 §5.10 一致）；45 秒内没有停顿就在能量最低处强切，两侧多送 300–500 ms 上下文、只保留核心区输出。上限以 8B 输入上限为准（§13）。
尾部顺延上传分片最后一个停顿之后的音频并入下一批。常规批最多等 20 分钟，到时单独识别；立即同步不等；会话结束（手机上报领夹断开或电量告警）不等。
立即同步App 请求后网关检查配额（每天 3 次），标记该用户的同步窗口；手机把未满 5 分钟的当前分片截断上传，chunk_id 照常按起始帧序号；窗口内的作业进入立即同步队列，单元调度器在最新一帧处临时关闭单元。
可见时机片段在 G7 完成后才对 App 可见；单元关闭后 G8 生成，纪要可见 P90 ≤30 分钟目标。
迟到与重开迟到分片的作业照常处理；单元调度器发现片段落入已关闭单元，递增代次并重新生成。G8 生成完成时如代次已变，丢弃结果，以免旧纪要覆盖新纪要。

热词服务不可用拿不到偏置表先用按用户 × 小时缓存的表；没有缓存就排队，到作业截止时间仍不可用才无偏置解码并标 no_bias。音频删除后无法补救，所以不急于降级
600M 池不可用没有对齐就切不出轮次排队；超过 12 小时跳过交叉校验，可疑片段一律标 low_confidence，对齐退回 8B 时间戳（若有，§13），G5 按整段判，标 degraded
CPU 小模型不可用G2、G5 的输入缺失排队，不降级：没有 VAD 与嵌入就无法安全判定
小 LLM 不可用G7 完不成，片段不可见排队；音频删除不受影响。App 显示“识别中”
中 LLM 不可用纪要延迟转写照常可见；单元停在“生成纪要”
密钥服务不可用无法加解密失败即关闭：网关拒收上传，手机继续暂存（最长 7 天）；音频作业暂停
某个数据库分片不可用该分片上的用户只影响这些用户；其余照常

模型与提示词的版本

  • 每个环节的模型、阈值、提示词都有版本，写入片段的 versions。
  • 新版本先在自建评测集上与当前版本配对比较（§9），不回退才进入灰度。
  • 灰度按用户比例分流，只比线上统计：拒绝、隔离、未知说话人占比，放回率，改标与改字率，“这不是我说的”反馈率。音频不保留，不能拿线上音频回放。
  • 回滚只改配置；已处理的片段不重跑。

LLM 调用的约束

  • 输入只有文字与元数据；隔离档只以“时段 + 原因”的占位出现。
  • 输出是结构化结果，先按模式校验，不合格重试一次后丢弃。G6 的结果被丢弃时，片段按“未判定”进 G7：不降级、不标背景，但相关性一维记为未满足，不进纪要上下文、已核实待办与记忆。
  • LLM 只提议，G8 规则由代码判定：引用的片段必须属于该单元，说话人、证据级与待办类别相符，否则降为未核实或丢弃。
  • 提示词前缀保持稳定，单元内容放在末尾，以便利用前缀缓存。

安全

  • 密钥：信封加密，每个用户一把数据密钥，由密钥服务的主密钥包裹；音频、质心、声纹模板、片段文字都用它加密。
  • 权限：只有音频作业的服务账号能读短期音频桶；文字段与 App 接口没有任何读音频的权限或接口。
  • 鉴权：用户令牌短期有效；领夹与用户绑定，清单中的 device_id 必须属于该用户。
  • 日志：只记 ID、时长、计数与分数分布；错误信息只带错误码；LLM 的输入输出、模型服务的请求体都不记录。
  • 人工访问：没有人工访问音频的途径；访问用户文字须有用户授权的工单，并留审计记录。

监控与告警

  • 时延：常规 P90 ≤3 小时、立即同步 P90 ≤10 分钟、纪要 P90 ≤30 分钟；按截止时间预测的超时作业数。
  • 删除链：音频最大滞留时长（24 小时告警）、落盘到删除 P99、删除到回执 P99、到期未删条数。
  • 容量：各队列深度、各池利用率、借用的预留容量。
  • 质量（§9 线上监控）：按原因的拒绝与隔离占比、未知说话人占比、放回率、改标与改字率、“这不是我说的”反馈率，按模型版本分开，偏离对照带即告警。
上线前的故障注入清单
  • 在 ①、②、③ 前后各杀一次作业进程：无遗留音频，无重复片段，回执最终送达
  • 同一分片重复上传、乱序上传、回执丢失后重传：片段不重复，已删分片不再收音频
  • 同一用户的两个作业同时提交簇状态：一方冲突后重新归簇，簇计数正确
  • G8 生成期间单元重开：旧代次的结果被丢弃
  • 8B 池停 13 小时：降级识别、标 degraded，恢复后不重跑
  • 密钥服务不可用：网关拒收，手机暂存，恢复后补传
  • 生命周期规则失效（模拟）：巡检在 24 小时内告警
  • 用户擦除与上传并发：擦除时段内的分片在写入后被复查删除

§7删除链

设备等手机回执、手机等云端回执、云端等识别结果落盘。音频在 G5 判定与对齐完成后即删；内容门控、纠错、裁决、纪要、待办、记忆都只读文字，不在等待之列。领夹在手机回执后立即擦除，不只是标为可覆盖。写进片段的只有标量、区间与标签（§5.10）；高维的声学派生物只留他人簇质心，业务日结束后 12 小时删除。

放弃了什么

模型升级后不能重转历史音频；误拒或误判无法回到声学层复核；用户改字时无法回听。

为什么接受

长期保存全天录音是最大的隐私风险源，还包括大量他人的声音；需求明确要求删除链。

怎么缓解

  • 上线前充分评测
  • 低置信区间保留 top-3 候选，改字时点选
  • 隔离区 7 天纠正窗口
  • 不设保留音频的后门

其他保护：日志与指标只记 ID、时长、计数与分数分布；传输 TLS；暂存与对象存储按用户数据密钥加密。短期音频桶关闭版本控制、不进任何备份、不做跨区域复制，以对象存储的硬删除为准，不依赖软删除或回收站。

对外承诺与保留期限

“转写后不保留音频”说的是识别完成之后。识别之前，音频会在三端短暂存在；声纹派生物不是音频，但用户同样关心。对外的隐私说明按下表写，不写成“从不存音频”。

数据在哪里最长保留
未识别的音频领夹到手机回执为止；手机不在身边时最多到 Flash 写满后停录（128 MB 约 17 小时）
未识别的音频手机到云端识别完成的回执为止，最长 7 天，超期删除并登记缺口
未识别的音频云端识别完成即删；排队、等下一批补齐尾部、服务故障等待合计最长 72 小时

机主声纹模板云端到用户删除或重新注册；注册音频即删
他人声音特征（簇质心）云端业务日结束后 12 小时，即最晚次日 16:00；不跨天关联
转写文字云端接受档按用户留存设置；隔离档 7 天

§10分阶段路线

一期在现有设备上把软件链路做完整，必须能独立上线；二期验证 VPU 与播放声可分性；三期做模型级优化与降本。

一期

做：手机端全套、云端 G2–G8、8B + 600M、声纹注册与一期规则、三类热词、纠错（评测后开）、三档与隔离区、对话单元、两级队列、评测集；§5.10 的一期必须项与各变体的配对评测；16 kb/s Opus 与领夹远场的域差测试，有收益的适配一期合入。

退出标准目标

  1. S1 上限 <2%
  2. S2 时间线级 ≤1%，证据级 ≤0.5%（过渡）
  3. R1 ≥98%，R3 <2%，R4 ≤3%
  4. O1 ≥85%（过渡）
  5. CER 近场 <8%；远场、全天按基线冻结
  6. R2a、R2b 按类别报告并给出差距；外放远端会议的保留率单报
  7. N2 ≥80%、N3 ≤5%、N4 ≥85%（报告覆盖率），N1 报告；纪要 P90 ≤30 分钟（单元关闭后）
  8. 常规 P90 ≤3 小时，立即同步 P90 ≤10 分钟
  9. 删除链故障注入后三端无遗留音频：读出领夹 Flash 的原始块、检查对象存储的历史版本与备份；§5.14 故障注入清单全部通过
  10. 实测成本 ≤¥27/人/月

二期

做：双麦 + VPU/骨导（两套对照）+ IMU 原型 10–20 台；G0；VPU 特征上报；融合规则；空间特征；回放检测训练；功耗实测。VPU 验证必须用真人自然发声。

退出标准目标

  1. VPU 命中 ≥95%，外部声误报 ≤2%，“无效”识别 ≥95%；不达标换形态再测，仍不达标退回一期规则
  2. O1 ≥90%，S2 时间线级 ≤1%、证据级 ≤0.2%；同音色家人最差一对证据级 ≤2%
  3. S4 疑似回放拦截 ≥95%
  4. R2b ≥90%（在 R4 ≤2% 下），外放远端会议保留率单独报告，“电视普通对话”单独结论
  5. 平均功耗 ≤5 mW，续航 ≥24 h
  6. 若开启可选的播放跳过：真人误拒增量 ≤0.2 个百分点

三期

做：8B 深度领域适配（在一期适配基础上扩大口音与远场覆盖）；偏置专项训练；以 VPU 为条件的判定模型取代手写融合表；扩充重录语料；手机 VAD 蒸馏；8B 量化与批处理；可选家人自愿注册“已知他人”。

退出标准目标

  1. CER 全场景达标
  2. O1 ≥92%，S2 不回退
  3. 8B ≤¥0.08/h 或成本 ≤¥22/人/月
  4. 每次更新通过回归
