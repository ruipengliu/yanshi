5.10 模块能力与效果规格

5.1–5.9 写的是处置规则，这一节写各模块的判别能力本身。问卷前两位的问题（混入、归错人）能改善多少，取决于能力与规则的组合。本节结论经两轮对辩形成：先请外部模型独立评估，再把我们的判断交给它逐条反驳，事实性陈述由我们核实后取舍。下面的参数是建议的初始值，须在调参集上实测后冻结。模块能力表之后是各模块的选型、算法原理与关键指标。

G5 是声学证据的最终完成点

音频删除后，只能读文字，无法再做任何声学判断。所以凡是需要音频的工作，都在 G5 定稿前做完：批内重聚类与重分段、候选的声学评分、限额的局部复核。之后的环节只读文字，承诺不变。

删音频前写进片段的证据

词级候选及来源、候选的声学评分、全量声学支持与局部低支持区间、归属模糊区间、实际重叠范围、来源证据及其覆盖范围、相对声级与直达/混响比、二期的 VPU 有效性与同步质量。只存标量、区间与标签，不存高维声学表示，免得变相保留重跑能力。

能力与规则联合验收

每个模块单独评测，也看组合后的最终产物。阈值只在调参集选定，冻结后到测试集验收；同时报告产出覆盖率，避免靠大量弃权换来漂亮的精度。

VAD 与识别窗口（G2）双向时序平滑的非流式 VAD，启停双阈值。识别窗口与说话人轮次独立，目标 15–45 秒，优先在自然停顿切；强切处保留 300–500 ms 声学上下文，只输出核心区并去重。不把短回应拆成单独请求。说话人与交互分析用原始时间，不用拼接后的间隔。条件换人切分：换人检测达到调参集上的高精度工作点、边界附近没有重叠、两侧各有 ≥5 秒语音才切。前文提示：同一对话的可靠前文，≤128 token。两者做 2×2 对照。语音漏检时长、短回应召回、首尾音节截断率、切点附近 CER、前文复制率

专名纠错改为可弃权的候选重排，原文始终是候选之一。个人专名同样要求声学支持或模型分歧；证据不足时只在时间线上列出候选，不自动替换，因为人名错会直接改变承担人。候选的声学评分在删音频前完成。相似度按语言选音系：中文拼音、英文音素。受约束 LLM 在 N-best 中选择，含“保持原文”。修改精确率、把对的改错率、承担人因纠错改变的比例、候选 oracle 准确率
幻觉防护（G4）全部片段复用 600M 的 CTC 输出，计算按长度与语种校准的声学支持分数，并标出局部低支持区间（整段均值会掩盖一个错掉的否定词）。低支持只单向触发：局部复核、标 low_confidence、取消该区间支撑已核实待办与记忆的资格；不单独据此拒绝或隔离真人语音。高支持不证明文字正确。限额局部复核的触发策略。非语音插入、语音中的无依据插入、真实重复与混说的误触发、两个模型同时出错的漏检
说话人与机主（G5）删音频前做一次批内优化：重叠感知分段、质量加权嵌入、聚类与重分段，再关联日内簇。簇更新排除重叠、疑似回放和低质量短音频；给新轮次打分时，不用已经包含它自己的质心。重叠只把实际重叠和边界模糊的区间记为未知，不扩大到整段。短回应不因紧邻他人就自动记未知，要结合前后长轮次与帧级证据；无法验证的承诺仍弃权。近场特征（相对声级、直达/混响比）作为模型输入，仍不能单独授予机主。得分归一化、概率校准、模板适配分开规定。personal VAD / TS-VAD 作为附加的机主活动证据；AS-norm 加校准；逐轮次嵌入缓存（见下）；少量高价值重叠试验目标说话人提取。二期：VPU 融合按有效性与同步误差校准，直接测融合后的证据级误判；联合 speaker-attributed ASR 作为挑战者。词级归属错误（O3）、机主身份固定的 SA-CER、短回应召回、DER/JER、每用户每天错人事件数。标签可任意置换的指标不能单独证明“机主认对了”
相关性（G6）从“媒体文风分类”扩成对话相关性判定：综合称呼、问答关系、语义承接、连续互动、声源证据与场景先验；以片段为主，簇级结论作先验。时间相邻只是一项特征，日历只是先验，日历会议同样评估。窗口按时间与 token 双重限制，不按固定 20 轮。LLM 给的媒体概率须在标注集上校准后才能当概率用。小 LLM 与专用分类器对照。N3 纪要混入、相关内容漏失；邻座闲聊、电视普通对话、机主少发言的会议、引用媒体内容、外放远端五个切片
裁决与资格（G7）来源安全由档位表达（只有接受档往下走）；资格按 D45 拆成四维：身份、文字可靠性、相关性、语义支持，四维分别决定时间线、纪要、已核实待办、记忆的写入资格（下表）。确证非语音这类硬条件维持严格规则；概率判断先融合、处理冲突，再决定是否隔离，免得多条保守规则取并集后突破 R4。—R3、R4，各产物的风险—覆盖曲线；按维度真正关闭模块做配对消融，不能只统计 reasons
对话单元分两层：事件边界（静默、参与者分布——计算时排除机主、场景、开始与结束话语）和事件内的主题边界（语义转移、议程线索）。日历是先验，不强制把整段声音归为一场会。“机主 ≥3 句”作为一期基线保留，另加例外：机主明确口述的记录或提醒，一句也生成。语义切分模型；以相关性与任务证据门槛替换“3 句”规则。N1 误合并/误切分、N2、跨边界的任务遗漏、单句口述、同一批人连开两场会
纪要、待办、记忆（G8）先抽原子事件，再生成产物。每条带原文跨度、发言者、被请求者、承担人、动作、对象、期限、条件、否定和状态（请求、知悉、接受、拒绝、撤销）；期限以录音当地日期为锚解析“明天下午”；后来的改口与撤销会取消前面的承诺。纪要以已核实的事实、决定、未决问题为基础，长单元先抽证据再聚合。记忆区分本人事实、引用他人、假设、愿望和临时状态。代码校验引用范围、字段与资格；引用是否真的支持结论，由核验步骤判断，不能只看引用 ID 存在。更强的模型只处理疑难：承担人或状态冲突、跨轮次撤销。按 20% token 工作量替换约 +¥0.9/月。全量换强不设期次，由净收益决定。N4 待办的动作、承担人、期限、状态联合正确率；纪要事实精度与 N2；记忆事实错误率；请求、知悉、接受、拒绝、撤销的最小对照集

效果预算

按 5 小时高位口径，基线约 ¥25.2/月，离 ¥27 只剩约 ¥1.8。5% 音频的局部复核约 +¥0.75，G8 疑难升级约 +¥0.9，合计 ¥1.65，已接近全部余量。所以一期默认只启用复用现有计算的能力：CTC 声学支持（复用对齐）、批内重聚类（复用嵌入）、结构化抽取（同一模型，不加调用）。复核与升级作为变体，联合成本过线才启用。这笔余量还没扣立即同步的峰值预留（§8，+¥0–3）：同步若集中在下班时段，高位口径下已无余量，复核与升级只能靠压低预留或其他环节的节省腾出。典型 3 小时用户余量更大，但验收按高位口径。

逐轮次嵌入缓存（一期变体）

默认在批内重聚类后即删。变体比较批内、最长 2 小时、最长 6 小时三档；只有跨批的 S2、O1、N3、N4 有明确净收益才采用，并取最短有效期限。若采用：音频仍在 G5 后即删；只保留嵌入、轮次对应与质量权重，仅用于同用户、同业务日内当前对话的归属修订；单元首次关闭后的重聚类完成即删，任何情况下不超过提取后 6 小时；续说、补传、用户编辑都不延长期限，单元重开也不恢复；不用于跨天关联、模板更新、训练或属性推断。采用时同步修改 §7 的例外说明。

§9评测

28 小时自建评测集，5 小时精标；安全类指标按 95% 置信上限验收。只用自建采集，不使用线上用户音频。
