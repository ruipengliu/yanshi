详细设计 · 说话人与热词

机主判定（G5）、声纹注册、热词检索与偏置表、音系召回与专名纠错。G5 是声学证据的最终完成点：凡要音频的判断都在这里做完，之后只剩文字。

读法。每节按同一模板：职责与边界、原理、流程、数据结构与接口、算法、参数、失败与恢复、测试与验收、未决项。G5、音系召回与候选声学评分都在音频作业内运行（详设 5–9 之后、落盘 ① 之前）；专名纠错的重排在文字管线里运行，只读已写进片段的标量。共同约定沿用识别页：区间左闭右开；声学运算只用原始设备时间轴，不用去静音后的拼接时间；文字跨度用 Unicode 码点并带 text_revision；缺失的分数为空并带缺失原因，不填 0；没有完成标定的配置不得自动授予证据级或自动替换专名。

职责与边界

G5 输出三个互相独立的判断，不能合成一个 owner_score：

判断输出不能推出
谁在说局部说话人轨迹、轮次、当天的簇簇号不是身份
是否机主owner / other / unknown，是否达到证据级声纹高不证明现场发声
声源与文字限制实际重叠、归属模糊、疑似回放的区间高 CTC 支持不证明字形正确（D47）
  • 把 8B 的字按 600M 的对齐落到轮次上；一个识别窗口可以包含多个轮次，一个轮次也可以跨窗口。
  • 删音频前做完：批内重聚类与重分段、候选声学评分（详设 13）、限额局部复核（一期变体）。G5 落盘后不再有任何声学计算。
  • 不做：相关性（G6）、参与者与背景（单元关闭时，详设 16）、簇的命名（单元关闭时由 LLM 建议、用户确认）。

原理

  • 四步：局部分段 → 批内聚类与重分段 → 日内关联 → 身份校准。 说话人分离与机主验证分开训练、分开验收。Powerset 分段把“无人 / 单人 / 两人同时”建模为类别，能表达重叠；它的局部槽位编号只在一个分段窗口内有意义，要靠嵌入与聚类连起来，不能当身份。
  • 声纹验证。 嵌入网络（CAM++、ERes2NetV2 一类）把语音映射为定长向量；与注册模板的余弦分经 AS-norm 对称归一，可能缓解说话人与信道造成的分数分布失配，但不保证消除（Matějka 等，Interspeech 2017）。AS-norm 只是归一化，不是概率：再用带真实身份标签的试验训练校准器，输入归一化分、有效时长、质量、模板质量、独立簇证据与缺失标志，输出对数似然比。时长等条件会改变分数分布，长句的校准器不能直接用于短回应。
  • 簇比轮次稳，但不能自证。 短轮次的嵌入噪声大，同一人当天累积的簇质心稳得多；给一个轮次打分时，簇证据必须扣掉该轮次自己（以及与它共享上下文音频的部分）的贡献。“簇像不像机主”（cluster_owner_score）和“这个轮次是否属于这个簇”（cluster_assignment_score）是两个分数。
  • 近场线索只作输入。 机主嘴到领夹约 20 cm、他人约 1.5 m，声级差约 17.5 dB估算；近处他人与开大的电视会破坏它，所以只进融合。单麦估计的 DRR 必须带估计方法与缺失状态，不能冒充二期的空间测量。
  • 宁可未知，不可错人。 误把他人当机主会产生错误的“我答应的”待办。T_high、T_evidence 按误判上限定，不随召回放宽；夹在中间的记未知。重叠只把实际重叠与边界模糊的区间记未知，不扩大到整个轮次。
  • 一期的限制。 重叠检测不是语音分离：混合音频产出的一串字不能可靠分给两个人。音频删除后簇只剩质心，无法拆开已经误合并的簇，所以拆分与合并都要在批内做完。不维护“持续学习机主声音”的模板（防投毒，详设 11）。

  • 归属一经提交即冻结。 时区取清单的 tz（录音时手机的时区）；多设备时区不一致时以该分片自己的清单为准。day_id 在 ① 时按当时的时钟映射版本与时区政策版本算出，写进片段；之后的时钟重拟合或时区改动不让已提交片段换日，也不延长已建簇的 expires_at（簇建立时固定）。旅行跨时区时，一次录音可能落进与日历日不同的业务日，这是有意的：业务日跟着录音时刻走。

  • 迟到：录音所在业务日的簇还没到期（expires_at 之前）就照常关联；已到期的，只在本作业内聚类，簇号用 late:<day_id>:<job_id> 命名空间；G5 后丢弃质心与嵌入，片段里保留这个 late 簇号作稳定引用（同一作业内的“他人 A”仍是同一个人），不复活已删除的质心，也不另外保留 12 小时。

算法

字落轮次。 不用时间戳中点：设字 c 的对齐帧权重为 w_c(t)（来自 600M 对齐，去掉远处的 blank 尾巴），轨迹 k 的活动概率为 p_k(t)，覆盖分 A(c,k) = Σ_t w_c(t)·p_k(t) / Σ_t w_c(t)。

def assign_char(ch, activity, cfg):
    if not ch.alignment_valid: return ambiguous("unaligned")
    sup = alignment_support(ch)                                   # 非 blank 占用帧 + 按中点分配的 blank
    if intersects(sup, activity.overlap): return ambiguous("actual_overlap")
    if boundary_mass(sup, activity) > cfg.max_boundary_mass: return ambiguous("speaker_boundary")
    best, second = top2(A(ch, k) for k in activity.tracks)
    if best.score < cfg.assign_min: return ambiguous("insufficient_coverage")
    if best.score - second.score < cfg.assign_margin: return ambiguous("competing_speaker")
    return assigned(best.track)

def link_slots(seg_windows):                                     # 分段模型的局部槽位 → 作业内轨迹
    tracks = Tracks()
    for prev, cur in pairwise(seg_windows):                      # 相邻分段窗口有重叠区（步长 < 窗长）
        sim = activity_correlation(prev.slots, cur.slots, on=prev.overlap_with(cur))
        for a, b in hungarian(sim, min_corr=0.5):                # 重叠区里活动曲线相关 ≥0.5 才连
            tracks.link(prev.slot(a), cur.slot(b))
        # 没连上的槽位开新轨迹；之后靠嵌入聚类合并
    return tracks

def optimize_batch(turns, day, g3seg, cfg):
    usable = [t for t in turns if t.clean_speech_ms >= 1500 and t.quality_ok and not t.overlap

def update_centroid(c, contribs):                                # 未单位化均值 m 与总权重 W
    W2 = c.total_weight + sum(w for _, w in contribs)
    c.mean = (c.total_weight * c.mean + sum(w * e for e, w in contribs)) / W2
    c.total_weight = W2

def tier(p, t, job):
    if t.voiceprint is None: return Decision("unknown", reasons=["no_voiceprint"])   # 硬前置条件先于阈值
    if t.state in ("overlap", "ambiguous"): return Decision("unknown", reasons=[t.state])
    evidence_ok = (t.single_speaker_ms >= 1000                    # 有效单人语音时长，不含静音与重叠
                   and not near_overlap(t, ms=500) and t.calibrated_branch_ok
                   and job.exec.alignment_source == "600m")      # 降级期间不授证据级
    if p >= T_EVIDENCE and evidence_ok:
        return Decision("owner", evidence_grade="identity_evidence", owner_score=p)
    if p >= T_HIGH: return Decision("owner", evidence_grade="timeline", owner_score=p)
    if p <= T_LOW:  return Decision("other", cluster_id=t.cluster_id, owner_score=p)
    return Decision("unknown", owner_score=p)

三档阈值的选法（在最终决策链上选，不在裸声纹分的 ROC 上选）：

  1. 按机主、他人真实身份与录制会话分组，划分训练、校准、阈值选择、验收四个集合，同一个人不跨集合。
  2. T_high 取满足“时间线级 S2 的单侧 95% 上界 ≤1%”的最低阈值。
  3. T_evidence > T_high，取满足“证据级 S2 上界 ≤0.5%”的最低阈值，另报与 0.2% 长期目标的距离。
  4. T_low 只决定“未知”与“他人”的分界，降低它不能提高 O1。它按“机主被判为他人”的比例选：分母是参考机主发言时长，目标是点估计 ≤2%（同时报单侧 95% 上界，但不作硬门槛，因为这是召回侧的错误）。这是提案“按召回定”的可执行口径。
  5. 安全上限固定后再检查 O1 ≥85%。不满足就改模型、注册质量或短轮次处理，不降低安全阈值换召回。
  6. 短轮次、家人、回放、不同信噪比单独报；数据不足的分支保持弃权。

S2 的主口径沿用 §9 的“参考发言比例”，参考发言的划分在评测前固定。有错误时按真实说话人整组重抽样，同一人的回放归入同组。零错误时不能用普通 bootstrap 得到“上界为零”。1 − 0.05^(1/n) 是“n 个独立他人中至少一人被误判”的人级事件上界：60 人约 4.87%，证明 ≤0.5% 约需 598 人。它不是按发言计的 S2 上界；要把两者接起来，评测集须固定每人的发言配额（同等时长），S2 按人均匀加权，此时人级上界是 S2 的保守上界。两种口径都报，同一人的大量句子不能充当独立单位。

用户擦除擦除屏障优先于任何重试与复核

复核（一期变体，e-trigger、e-rereview）：

  • 预算：每个作业可复核的音频秒数 = 该作业有效语音秒数 × 5%，按作业预留，不跨作业借用；按上下文扩展后的实际重识别秒数计，重叠区间先合并，崩溃重试的成本另记。
  • 排序：gain = P(错) × 代价 ÷ 额外秒数。P(错) 来自已校准的信号（低支持、交叉校验分歧、归属模糊）；代价按类别固定：承担人与关键字段 5、专名 2、其他 1（变体参数，配对评测时扫描）。
  • 接受规则：同一帧区间上，新结果的 600M 支持 g_label 比原结果高至少 0.5，且独立 600M 解码（若有）与新结果一致，才替换；归属复核要求新的覆盖分领先次优 ≥0.2。否则保留原文与标记。每个区间最多一轮。

测试与验收

  • A 说 → A、B 重叠 → A 继续：只有重叠区未知。200–800 ms 回应、跨窗口的同人长句、换人点落在一个中文词内部。
  • 同一人两种声态、相似音色的家人、响亮的远场他人、轻声的机主；本机外放机主录音、外部音箱回放、外放远端会议、真人与媒体同时发声。
  • 当前轮次加入质心前后的打分对照，确认已排除自身；疑似回放轮次的簇贡献被撤销；相邻分段窗口的槽位连接正确。
  • 两个并发作业同时新建同一人的簇；一个重注册、一个提交；簇到期时提交；擦除时提交。① 前后、删除前后杀进程：无重复计数、无重复片段、旧租约无效。
  • 04:00 边界、时区变更、夏令时、乱序、超过 12 小时的迟到。
  • 指标（§5.10）：S2（时间线级 ≤1%、证据级 ≤0.5%，按上面的上界口径）、O1 ≥85%、证据级覆盖、O3、固定机主身份的 SA-CER、短回应召回、DER/JER、每用户每天错人事件数。标签可置换的 DER 改善不能替代机主身份验收。

与提案的差异

  • §5.6、c-owner：cluster_score 拆成 cluster_assignment_score 与 cluster_owner_score；簇存未单位化均值与总权重，不是“质心与计数”。
  • §6.2：每个片段一个 speaker，逐字归属靠片段切分表达，重叠区单独成片段。
  • §5.6：T_low 的口径改为“机主被判为他人”的上限。
  • §5.13：“600M 不可用后 G5 按整段判”按上面的失败表收紧：不授证据级、有换人点的窗口记未知。
  • §7、D18：到期后的迟到簇不保留质心。§9：由约 60 位他人推出数百有效样本需要相关性证据，不能据此宣称低误判上限已验证。

未决

  • 单麦 DRR 是否值得加入，看调参集上的增益；一期可以只用相对声级。
  • 逐轮次嵌入缓存（2 / 6 小时）是一期变体，只有跨批的 S2、O1、N3、N4 有净收益才采用，并同步改 §7：期限从提取时刻起算，不因补传或编辑刷新。

11声纹注册

契约：

职责与边界

  • 用领夹录约 1 分钟机主语音，生成声纹模板与近场声级基线；单独同意，可随时删除或重新注册。
  • 要防的是：旧录音直接提交、误录他人、多人混录、重注册投毒。不承诺挡住实时变声、实时合成或账号被他人控制后的冒认；账号认证、设备绑定与声纹一致，都不等于现实身份已核实。
  • 注册音频只在注册请求的内存中处理，不进短期音频桶与通用上传重试链；生成模板后即丢弃。
  • 不做：自动更新模板（防外放或冒认投毒）。

原理

  • 同一信道。 手机麦克风注册会造成信道失配，所以只接受领夹经 BLE 实时送来的帧。App 上报的 device_id 本身不能证明音频来自领夹：建议领夹用每设备的出厂密钥对注册帧做 MAC、云端校验（建议，非约束，依赖设备密钥的预置方式，§13）。MAC 至少覆盖 enrollment_id、challenge_id、nonce、boot_gen、帧序号、编码格式与音频字节，且只由领夹的采集路径生成，否则旧的合法帧可以被重新挂到新会话或拼接。MAC 只证明“这些字节出自这台领夹、属于这次挑战”，不防现场重放，也不证明真人在场。没有这项机制时，“来自领夹”只是客户端声明，作为已知边界记录。
  • 一次性挑战。 静态朗读稿可以预先准备。服务器逐段下发挑战：朗读段从音素均衡语料中抽，加入本次随机短语；开放回答要求引用本次的随机元素。这主要挡住旧录音复用；对实时合成的效果是待实测的假设，不作活体宣传。
  • 分项检查，分项失败码。 音素覆盖、内容响应、单人一致性与回放分别检查。“多数段像同一个人”不能作为通过理由：混入一段他人，就该补录或拒绝，而不是丢掉那段继续。
  • 只存一个模板。 多模板取最高分会改变误判分布，沿用单模板阈值就不成立；轻声与正常声分开的多模板是显式变体。

状态机

CREATED → CONSENTED → CHALLENGING → QUALITY_CHECKED → TEMPLATE_READY → ACTIVATED → AUDIO_PURGED；异常终态 CANCELLED | EXPIRED | REJECTED，进入任一终态都立即清除注册音频与逐段嵌入。

  • 新模板只有全部检查通过才原子激活；激活事务同时递增 voiceprint_epoch，正在用旧版本提交的 G5 作业因此冲突重算（详设 10）。
  • 重注册失败不破坏旧模板；用户主动删除旧模板则立即失效。
  • 已完成 ① 的历史片段保持原标签，versions 记录所用模板版本（§5.4）。

算法

def check_part(part, ch):                                  # 每段一次
    if (r := idempotent_result(part)): return r            # 同一请求的重传先返回原结果，再查 nonce
    require_unused_nonce(part, ch); require_bound_source(part)        # 帧 MAC 或绑定校验
    pcm = decode(part.frames)                              # 只在内存
    q = measure(pcm)
    if q.valid_speech_ms < 3000 or q.snr_db < 15 or q.clip_ratio > 0.005: return retake(q)
    if multi_speaker(pcm): return retake("multi_speaker")
    text = asr_600m(pcm)
    if ch.kind == "read" and phonetic_match(text, ch.script) < 0.9: return retake("challenge_mismatch")
    if ch.kind == "spontaneous" and not contains_all(text, ch.required_elements, phonetic=True):
        return retake("challenge_mismatch")                # 开放回答只核验要求出现的随机元素
    if q.replay_score is None: return retake("replay_unscored")        # 证据缺失不当通过
    if q.replay_score >= REPLAY_ENROLL: return reject("replay")
    return accepted(embed(clean_single_speaker(pcm)), q)

def activate(parts):
    require(len(parts.read) >= 3 and len(parts.spontaneous) >= 3)
    require(total_ms(parts) >= 35_000 and total_ms(parts.read) >= 15_000 and total_ms(parts.spontaneous) >= 15_000)
    E = [p.emb for p in parts]
    loo = [same_speaker_p(e, mean(E without e)) for e in E]          # 每段对其余段的留一分
    if min(loo) < 0.99 or min_pair(E) < PAIR_MIN: return reject("inconsistent_speakers")
    tpl = l2norm(weighted_mean(E, bounded_quality_weights(parts)))
    with txn():                                            # 同一事务内重查，再撤销旧版并激活
        if (r := idempotent_result(req)): return r
        require(session.state == "QUALITY_CHECKED" and consent_active(session) and not erased(user))
        require(current_epoch() == req.expected_voiceprint_epoch)      # CAS：两个注册会话不能互相覆盖
        v = store(tpl, level_baseline_db=median_level(parts), epoch=req.expected_voiceprint_epoch + 1)
    zeroize(parts)                                         # 清除音频与逐段嵌入；写入失败不能报成功
    return v
  • 得分漂移提示：只看证据级轮次的分数会有选择偏差（漂移后低分的轮次先被门槛剔除，剩下的中位数不降）。所以每天在 G5 里按模板版本与模型版本，聚合所有被关联到机主簇的轮次的原始余弦分位数（P10、P50）、证据级覆盖率与样本数，存成每用户每天一行统计（不含内容，随用户擦除）。证据级覆盖率比注册后第一周下降 ≥30%，或 P50 下降 ≥0.08 且样本数 ≥50 时，提示重新注册。只提示，不自动更新。
  • 重注册不要求“必须像旧声纹”，否则真实的声音变化会被锁死；改为要求额外的账号认证与完整的新挑战。

失败与恢复

  • nonce 只用一次；同一请求重复提交返回原结果，换了内容的重复请求拒绝。
  • 不能证明音频来自绑定的领夹时，不悄悄退回手机麦克风。
  • 中断即删除临时音频；恢复时重新下发挑战，不从持久化录音恢复。
  • 激活前崩溃保持旧版本；激活成功、响应丢失时按幂等键返回新版本，不再生成另一个版本。
  • 同意撤回与用户删除优先于激活事务。
  • 声纹模型升级后，旧模板不能与新模型的嵌入直接比较：保留旧模型的打分服务直到用户重新注册，或做经过独立验证的显式迁移。

测试与验收

  • 冒认分三种，验收不同：混入他人（六段里有一段或交替回答）必须被检出；外放回放、手机麦克风录音、旧挑战重放、跨设备伪装应被拒绝；账号持有人主动用他人的声音注册属于已声明的身份边界，系统无法知道谁才是真机主，不作为验收项。
  • 六段中混入一段他人、两人交替回答，应被检出。
  • 完成率、补录率、完成耗时、不同口音的误拒率；新用户、感冒后重注册、换领夹、轻声与正常声分开报。
  • 新模板对 G5 的配对效果；不能只凭注册内部一致性验收。重注册与 G5 并发、撤回同意与激活并发、激活响应丢失。
  • 注册结束后，临时音频、逐段嵌入及模型服务的请求体都不可恢复。

与提案的差异

  • §5.4 只写了质量检查：补防冒认的挑战、新旧模板切换的原子边界、分项失败码，以及注册失败、断网、崩溃时音频的去向。
  • §5.4 的“必须用领夹”缺来源验证协议；§13 增加“领夹注册帧 MAC 与设备密钥预置”。
  • §5.4、§5.13 补嵌入模型升级与已有模板的兼容关系。

12热词检索与偏置表

契约：

职责与边界

  • 维护三类词条与音系索引的版本；按录音时刻、当时的会议与用户所选行业包，为每个识别窗口生成一张有限的偏置表；向音系召回（详设 13）提供完整的可见词库。
  • D52 的边界写进接口校验：请求里不接收前文转写。用户明确改字可以形成个人词条；模型自动纠错与纪要不能。
  • “个人 / 行业 / 公共”是来源类别，“人名 / 组织 / 项目 / 产品 / 术语”是语义类别，分开存：前者决定配额与去重，后者决定纠错风险（详设 13）。
  • 不做：从纪要或转写回收专名；推断用户的行业。

原理

  • 偏置表是有限资源：条目越多，无关偏置造成的误插入越多，非热词字错率越差。所以先按场景筛到当下最可能出现的几百条，再按类别配额截断，保证当天新出现的低频项目名不被大量联系人挤掉。条数之外还有按真实 tokenizer 计的 token 上限。
  • 检索排序表达“当前可能说到什么”，不是“音频里说了什么”：参会人能提升排序，但不证明在场，也不证明字形正确。“个人 > 行业 > 公共”只用于同一词形的去重，同音不同词不合并，留给候选评分。
  • 不用前文转写：常规批并行解码时前文多半还没出来；用 8B 输出排序还会自我强化（D52）。
  • 缓存按完整的键，而不是“用户 × 小时”：同一小时里会议切换、个人词到期或被删、行业包切换，都必须形成新键。同键内的窗口拿到同一张表，提示词式偏置的前缀也能命中推理服务的缓存。

流程

  • 词条写入：RECEIVED → VALIDATED → NORMALIZED → INDEXED → ACTIVE（或 REJECTED）；之后 UPDATED | REVOKED | EXPIRED。
  • 公共与行业包发布：DRAFT → BUILT → OFFLINE_EVALUATED → PUBLISHED → RETIRED。词库与索引整体构建、评测通过后才切换发布指针，读取方只会看到完整的旧版或完整的新版。
  • 偏置表构建：固定各版本 → 取录音时刻覆盖的会议与项目 → 按有效期与授权过滤 → 三类分别排序 → 词形去重（合并来源与读音，不合并实体）→ 配额、条数、token 截断 → 确定性排序与内容哈希 → 缓存。
  • 窗口跨过生效边界：词条的生效区间与窗口核心区有交集就进表，不漏会议开头的专名；代价是最多一个窗口（≤45 s）的窗外偏置。背靠背会议另作截断：后一场会议开始后，前一场的会后余量在后一场的开始时刻截止，避免旧参会人偏置新会议。缓存键的上下文签名包含核心区两端各自落入的生效分区，跨分区的窗口不复用只按起点算的表。泄漏按每种生效边界（会前、会后、背靠背、项目归档、个人词到期）分别统计。

个人词按显式的优先级分层，不用一个连续加权分，避免关键项被淹没：

  1. 当前会议的参会人；
  2. 当前会议标题专名、当前项目名；
  3. 用户明确改过的专名；
  4. 其他生效的个人词。

同层内按联系频次、最近联系、来源可信度、稳定 ID 排序。

行业词：S = 0.55·F + 0.30·J_text + 0.15·J_phone。F 是包内 log(1+频次) 的分位数；J_text、J_phone 是与当前项目名、会议标题专名的字面 n-gram 与音节相似度；没有上下文时只用 F。多个行业包先按用户选择分配名额，再比较包内分位数，不直接比较不同包的原始词频。

def select_bias(personal, industry, public, max_entries=300, max_tokens=2048):
    g = dedupe_same_surface(personal, industry, public, precedence=["personal", "industry", "public"])
    sel = Selection(max_entries, max_tokens)
    sel.take(g.industry, upto=60); sel.take(g.public, upto=20)      # 先保底
    sel.take(g.personal, upto=220)
    while sel.has_room():                                          # 空出的名额顺延：个人 → 行业 → 公共
        item = next_ranked(g, order=["personal", "industry", "public"], caps={"personal": 220})
        if item is None: break
        sel.add_if_fits(item)                                      # 长词装不下时试后面的短词，记 token 截断
    sel.record_shortfall()                                         # 不足保底时报 quota_shortfall，不重复词条凑数
    return stable_order_and_hash(sel)

失败与恢复

  • 热词服务不可用：只复用版本、上下文、有效期都兼容的缓存，旧小时的表不算可用缓存；没有就排队，到详设 8 的无偏置启动时刻（可见截止 − 预计剩余）仍不可用，才无偏置解码并标 bias = none_deadline。音频删除后无法补救，所以不急于降级（§5.13）。
  • 一次识别绑定固定的偏置表快照（详设 8：重试用同一快照）。唯一例外是删除与撤权：热词服务在删除或撤权时递增该用户的 bias_revoke_epoch；作业在 CommitPlan 与 PersistResult 时校验它，不一致即拒绝提交，旧尝试因此被挡住。作业重新领取时用新快照，全部窗口重新解码（偏置会影响每个窗口），并在 versions 记录快照变化。
  • 撤销来源权限：撤销该来源支撑的词条、索引与缓存。删除一个热词不擦除已有时间线原文，只是之后不再取用或应用该候选。用户数据擦除覆盖所有词条、缓存、派生索引与在途作业（详设 18 的屏障）。
  • 复现：versions 记录偏置表的快照；个人词或会议上下文被删除后，版本号无法恢复内容，评测标“不可完全复现”，不为复现另存长期的个人快照。

测试与验收

  • 同用户同小时两场会议不混用缓存；录音后两天上传，按录音时刻而非上传时刻选词；窗口跨会议词的生效边界。
  • 几千条个人词、多个行业包、长英文术语下的条数与 token 双重预算；同词形多来源、同音不同词、同名不同人。
  • 撤销日历权限后旧同步包晚到；删除后缓存节点尚未刷新；发布一半失败。相同快照与配置生成完全相同的排序与哈希。
  • 偏置表召回 ≥97%目标；另报每一步的过滤损失、配额损失、token 截断损失、时间窗外误触发与缓存错用率；三类分别报，英文术语与中英混说单独切片（§5.3）。

原理

  • 8B 写错专名，多半写成发音相近的别的字：音节相近，字形可以完全不同。把文字转成拼音音节或英文音素，在 n-gram 倒排索引上找发音相近的词条，就能召回解码时没进偏置表、或进了表也没被选中的词。“全量库”指不受偏置表 300 条的截断，仍然执行用户、行业授权与有效期规则。召回分两条通道：可自动修改（录音时刻有效的词条）与仅建议（录音时刻已过期 7 天内的会议专名），后者带 suggest_only，重排后只能列为候选。
  • 索引侧精确，查询侧扩展。 中文索引保留整词读音路径、声母、韵母、声调、可接受的变调与读音来源；多音字不能只取当前上下文下的一种读音（ASR 错字本身会改变上下文判断），所以词典与用户给的读音优先，再加有限的备选路径。模糊音（z/zh、an/ang 等）在查询侧按代价展开，不全量免费等价化，避免索引组合爆炸。
  • 跨语言。 中文音译与英文不能直接比较拼音串与英文音素：优先用维护过的“中文音译别名 → 英文词条”；其次转到共同音素空间，按跨语言混淆代价召回。自动生成的音译桥接带 generated 标志，混说数据验证前只提供候选，不作为自动替换的独立依据。
  • 声学比较必须公平。 CTC 给一个标签序列的概率是所有合法对齐路径之和。原文与候选必须在同一音频帧区间、同一左右文字锚点、同一模型与规范化、同一路径聚合方式、同一分母上比较；不能一方用前向总概率、另一方用 Viterbi 最佳路径，也不能各自除以自己的 token 数。这一比较与详设 9 的 g_frame、g_label（全量支持诊断，用 Viterbi）是不同的量，字段分开。
  • 同音人名不能靠声学定字形。 “章威 / 张伟”读音相同时，CTC 分差主要反映模型学到的字形先验。该分差不能作为区分同音字形的独立声学证据，所以同音标 acoustic_discriminative = false；会改变人名身份的同音替换一期只列候选、由用户点选。这是对 D48 必要条件的收紧。
  • 决定改不改用三类证据：声学（上面的公平分差）、上下文先验（类别、是否在生效窗、是否本场参会人、是否用户改过）、语言模型（固定版本、共同上下文下的条件分差）。重排是一个条件 logit（多选一）模型：每个区间的选项是 {原文, 候选 1…k, 都不对}，标签是其中正确的那一项（原文本来就对 → 原文；换成某候选才对 → 该候选；都不对 → 都不对）。这样原文与“都不对”有可比较的分，而不是“哪个候选更像标准词”。训练集要有大量原文本来就对、以及正确词不在词库里的样本。

算法

候选区间：专名识别、8B 与 600M 的局部分歧、低支持区间；为了不漏掉“写成普通词的专名”，另枚举有界的中文短串（1–8 字）与英文词组（1–4 词，缩写另走一路）。区间不跨说话人边界、文字修订边界与保护区间；长项目名按词条的真实长度扩展查询。

模糊音代价（查询侧）：完全相同 0；只差声调 0.15；配置允许的 z/zh、c/ch、s/sh、an/ang 等 0.25；普通替换、插入、删除 1。n/l、f/h 只在用户显式选了口音配置时降为 0.25，否则走高代价通道。

def recall(text, lexicon, cfg):
    out = []
    for span in candidate_spans(text, cfg):
        paths = pronunciation_paths(span.text, max_paths=4, keep_context_alternatives=True)
        pool = union(exact_surface(span), ngram_index(paths, n=(2, 3)),
                     short_word_index(paths) if span.n_syllables <= 2 else [],   # 1-gram 通道，候选限额更严
                     english_spelling(span), curated_translit(span))
        pool = [mark_channel(e, span.audio_time) for e in pool if visible(e)]   # auto / suggest_only / 丢弃
        for e in pool:
            d = weighted_phonetic_distance(paths, e, FUZZY_COST)
            e.phonetic_sim = 1 - d / max(len(paths.best), len(e.units))         # 归一到 [0, 1]
        pool = [e for e in pool if e.phonetic_sim >= SIM_MIN[e.scope]]          # 行业、公共 0.75；个人 0.85
        out += diversify(sorted(pool, key=lambda e: -e.phonetic_sim), per_span=20)                    # 多条读音命中同一词只留一个候选，记全部路径
    return include_original(out)

def score_candidates(orig, cands, align, logp):                 # 作业内，删音频前
    reg = common_region(orig, align, left_anchor_tokens=2, right_anchor_tokens=2, pad_ms=300)  # 先定区间，候选不能自选
    L = {}
    for item in [orig] + cands:
        labels = tokenize(normalize(reg.left_text + item.text + reg.right_text))
        if has_unknown_label(labels):           L[item.id] = unsupported("ctc_vocabulary"); continue
        if not ctc_feasible(labels, reg.frames): L[item.id] = unsupported("insufficient_frames"); continue
        L[item.id] = ctc_forward_logsumexp(logp[reg.frames], labels)   # 相邻重复标签之间必须经过 blank
    if not valid(L[orig.id]): return mark_all("invalid_original_comparison")   # 原文无路径不等于候选自动胜出
    for c in cands:
        if valid(L[c.id]):
            c.acoustic.delta_per_frame = (L[c.id] - L[orig.id]) / len(reg.frames)
            c.acoustic.discriminative = not c.retrieval.exact_homophone

def propose(ev, cfg):                                           # 文字管线，默认关闭
    if ev.touches_protected: return abstain("protected_semantics")
    ranked = RERANK(ev)                                         # 条件 logit：P(原文)、P(候选 i)、P(都不对)，和为 1
    best = ranked.best_candidate
    if best is None or best.suggest_only or not category_gate(best, ev): return suggestions_only()
    if best.retrieval.exact_homophone and best.entity_type == "person": return suggestions_only("homophone_identity")
    if best.p < TAU[risk_class(best)]: return suggestions_only("insufficient_precision")
    if best.p - max(ranked.p_original, ranked.p_none, ranked.p_runner_up) < MARGIN:   # 概率差，初值 0.2
        return suggestions_only("ambiguous_choice")
    return validate(best, ev)

失败与恢复

  • G2P 失败：走词典与精确词形通道，不编造发音。正确词不在库：保持原文或弃权，闭集重排不能被迫选错。
  • 候选含 CTC 不支持的字符、英文或音译路径：标 unsupported，不填默认低分。8B 没有置信度：标缺失，走校准过的缺失分支，不当低置信。
  • 重排超时或输出不合法：保留原文与候选。G5 前崩溃：候选评分随作业重跑。G5 后重排崩溃：按 (segment_id, text_revision, evidence_version, policy_version) 幂等重试。
  • 用户已改字导致版本冲突：丢弃旧的模型 diff，不用旧偏移强行应用。词条在评分后被删除：取消该候选之后的自动应用。用户撤销某条模型 edit 后，同一证据版本不再自动应用它。
  • 用户改字的传播：同一单元内文字相同、或 alternatives 里含改后词的片段一并列出，由用户逐条或一键替换；只有用户确认的专名跨度作为 user_edit 来源的个人词条入库（详设 12）；否定、金额、日期与整句修改不进热词（D23）。

测试与验收

  • 多音姓氏、人名、项目名（含词典没覆盖的读音）；模糊音与普通近音；一字人名单报；英文缩写、字母读法、连读、中文音译、混合词。
  • 原文正确但偏置表里有高频同音词；正确词不在库、只在未选的行业包里、只在已过期的会议里。
  • 长短候选、相邻重复标签、原文无法对齐、候选含未知标签；故意让候选各用不同裁剪边界的错误实现，应被一致性测试抓出。
  • 人名紧邻“不”“可能”“改成”；含数字的产品名；跨轮次专名；三条 edit 互相重叠；Unicode 扩展字符；用户修改与模型修改并发。
  • 分层报四个瓶颈：词库覆盖 → 音系候选覆盖 → 声学评分覆盖 → 重排选择正确率。指标（§5.10）：修改精确率 ≥95%目标；改错 ≤0.2 / 千字；承担人因纠错改变的比例、弃权率、弃权时正确词在候选里的比例（报告）。

与提案的差异

  • h-evid、§5.5：600M 的独立解码、CTC 对齐与候选评分是三种证据，分别记覆盖状态。
  • e-align、c-fix：候选的声学比较补统一的比较域（同帧区间、同锚点、同分母、前向概率）。
  • D48、§5.5：“有声学支持或模型分歧”只是必要条件；同音人名不能据此自动认定字形。
  • §5.5、§6.2：diff 补偏移单位（码点）、文字版本、不重叠要求与修改后的坐标映射。
