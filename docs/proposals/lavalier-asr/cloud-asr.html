5.1 拒识级联

G3 证据来源判别力局限
声学回放特征回放检测模型，自建重录语料训练扬声器频响、压缩痕迹、房间混响好音箱近距离不明显；16 kb/s 抹掉细节
手机场景快照§4.4本机外放的时段几乎确定不覆盖电视、电脑、别人的手机；只说明当时有外放，不证明某句话来自手机
空间特征（二期双麦）方向长时间不变、直达/混响比低固定远场声源坐着不动的真人也是固定方向
交互特征（G6 计算）机主是否与该声源轮流发言电视不会接机主的话需识别之后才能算；线上会议的远端发言经外放也会与机主轮流，属于真人。单元级的参与者判定见 §5.8
VPU（二期）机主是否在发声只判机主有没有说话分不清电视和在场的真人

阈值：G3、G6 的阈值先满足真人误隔离 R4 上限（一期 ≤3%，二期 ≤2%），再报告此时的播放声拦截召回 R2，不为追召回把真人对话成批隔离。二期“跳过识别”是可选的降本手段，默认关闭；只有在真人误拒增量 ≤0.2 个百分点、且确有成本压力时才开启。

G4 幻觉防护

  • 无语音不送 8B（G2 保证）。
  • 健康检查：重复 ≥3、字速 >9 字/秒、压缩比、幻觉短语表（“谢谢观看”、字幕组署名…）、低置信、语种突变。
  • 可疑约 20%估算用 600M 重识别：幻觉型触发（重复、字速、压缩比、短语表、语种突变）且分歧大 → 隔离；只因低置信被抽查、分歧大 → 留在接受档，标 low_confidence，存 top-3 候选；无语音帧 → 拒绝。
  • 远场、口音下的真人语音常常低置信，600M 在这些地方也更容易与 8B 不一致，所以单凭分歧不隔离。
  • 不按“不通顺”删；不删与语音帧重叠的输出。
  • 全部片段计算 CTC 声学支持与局部低支持区间，只作单向触发（§5.10）。

G6 内容门控的边界

文风判断对风格化内容（广告、播报、歌词、剧台词）有效，对“电视里的普通对话”和“在场真人的闲聊”帮不上。这两类交给 §5.10 的相关性判定：称呼、问答关系、语义承接、连续互动与声源证据。无关媒体的拦截召回按内容类别报告（R2b）。

回放机主录音手段残余
一期本机外放 + 声纹高 + 纯声学回放特征（覆盖足够、不是未解开的混合声）→ 疑似回放；一期没有机主活动证据，缺失不当作“活动弱”；机主可能边听边说，单凭外放不判别的设备回放防不住
二期声纹高 + VPU 有效且静默 → 隔离VPU 失效时退回一期

中英混说：拼音召回对英文术语无效。英文热词按音素与字母拼写相似度召回，也召回 8B 写成中文音译的情况（如把 Kubernetes 写成“库伯内蒂斯”）；闭集纠错的候选同样可以是英文词。评测单独报中英混说切片。

评测要点：三类分别报告召回率与误触发率，另报英文术语、偏置表截断造成的召回损失、时间窗外误触发、行业包扩大后误触发的变化。误触发不达标时先缩小 N，再提高纠错门槛。

5.4 声纹注册（约 1 分钟）

  • 必须用领夹录：手机麦克风注册会造成信道失配。质量检查看信噪比、有效时长、各段嵌入的一致性。
  • 单独同意，与录音同意分开；可随时删除或重新注册。旧版本立即失效：尚未经过 G5 的轮次改用新版本判定，已判定的保持原标签，版本记在 versions。
  • 不自动更新，防外放或冒认投毒；得分分布持续下移时提示重新注册。

5.5 专名纠错（默认关闭）

输出只能是 diff

{
  "edits": [
    {"start": 12, "end": 14,
     "from": "章威", "to": "张伟",
     "candidate_id": "c3",
     "reason": "上下文为会议参会人"}
  ]
}

原识别文字与 diff 一起保存，App 可查看原识别、一键撤销。

校验（任一不过即丢弃该条）

  • from 与原文 [start,end) 完全一致
  • to 必须是该候选词：闭集选择
  • 不碰否定、数字日期、情态、改口标记
  • 按语言的音系相似度达到门槛（中文拼音、英文音素）
  • 每段最多 3 条
  • 满足按类别分级的证据门槛（下表）
类别额外证据要求
个人同样须有声学支持（删音频前完成候选评分）或 8B 与 600M 在此处不一致；否则只在时间线上列出候选，不自动替换。人名错会直接改变承担人
行业还须满足其一：8B 与 600M 在此处不一致，或 8B 在此处置信度低
公共同“行业”，并且不能只凭拼音相近触发

5.6 机主判定

流程

  1. 判定单位是说话人轮次：按换人点切分，再用 600M 的 CTC 对齐把字分到各轮次；一个识别分片可以包含多个轮次。
  2. 当天在线聚类（CAM++ / ERes2NetV2 一类）：只保留各簇质心与计数，新轮次归入已有簇或新建；逐轮次嵌入在批内重聚类后、G5 检查点删除（2 / 6 小时缓存是一期变体，§5.10）。簇号只在业务日内有效，质心在业务日结束后再留 12 小时供迟到分片使用，更晚到达的分片单独聚类、簇号标“迟到”。
  3. 轮次级得分 + 簇级得分（簇累计 ≥10 s 语音后）。
  4. <1.5 s 短轮次：结合簇得分、离簇中心距离、前后长轮次与帧级证据判断，不因紧邻他人就自动记为未知；仍拿不准的记为未知说话人。
  5. 只有实际重叠和边界模糊的区间记为未知说话人，不扩大到整段。
  6. 近场特征（相对声级、直达/混响比）作为模型输入，不能单独授予机主。
  7. 簇名：单元关闭时，LLM 按称呼线索（“小王你……”）和该会议时段的个人热词（日历参会人）给他人簇建议名字，用户确认后才显示。名字只在业务日内有效，不跨天关联，不形成他人身份档案。

证据级 ≠ 时间线级

证据级条件：声纹 ≥T_evidence（T_evidence ≥ T_high）；二期还要求 VPU 有效且有发声；不在重叠或邻近重叠处；片段 ≥1 s。

理由估算：他人每天可能说 2–3 小时，1% 误判就是每天 1–2 分钟被标成机主，足以每周产生数条错误的“我答应的”待办。

阈值只在调参集选定；T_high、T_evidence 按误判上限定，不随召回放宽，一期他人规模不足时取零误判的最低阈值并只报上界；T_low 按“机主被判为他人”的比例定（D69）。

5.8 入库闸门（G8）

产物规则
触发对话单元关闭后运行（§5.9）；单元重开时重新生成。用户改字、改标说话人、改背景标记都会重开所在单元
参与者与背景由 G6 的相关性判定（§5.10）：综合称呼、问答关系、语义承接、连续互动、声源证据与场景先验，以片段为主、簇级结论作先验。轮次前后相接只是一项特征，偶然相邻会把无关簇连进来；日历只是先验，日历会议同样评估。相关性低的他人片段或簇为背景：照常显示，不作纪要上下文，不支撑待办。用户可把背景改为参与者
纪要只读接受档；机主、参与者、未知说话人的话都可作上下文，背景簇不作上下文。隔离档只以占位出现：时段与原因，不含任何文字，让模型知道“当时在看视频”而读不到视频里的话。已归属机主少于 3 句的单元不生成纪要和待办（日历会议与机主明确口述的记录或提醒除外，用户可手动生成）
待办分类按承担人分四类，承担人与说话人分开记录：“这个交给小王”是机主原话，任务却是小王的
我答应的承担人是机主：至少引用一段证据级机主原话，且引用中的关键字段（否定、数字、日期、人名）没有低声学支持区间，引用确实支持“已接受”的状态；否则“未核实”：照常展示，不按期限提醒
对方要我做的承担人是机主：引用参与者的请求原话，并有机主的应答（时间线级即可）；机主没有应答则“未核实”
对方答应的承担人是参与者：至少引用一段该参与者的原话；否则“未核实”
我分派的承担人是参与者：引用机主原话（时间线级即可）；只提醒机主跟进，不记成对方的承诺
未知说话人与背景簇未知说话人只作纪要上下文，且同样须通过相关性判定（未知不等于相关）；两者都不能支撑任何待办，不进记忆
记忆只从证据级机主原话抽取关于机主本人的事实；他人话里关于机主的说法不写成事实；从他人话中得出的内容不进长期记忆（除非用户确认）
用户确认各操作只确认各自的维度（§5.10）：放回只确认内容可回到接受档；改标为机主确认身份，可达证据级身份；改标为他人可支撑“对方答应的”；改字与点选候选确认文字、不改说话人；确认待办确认语义与承担人
