# xinli 语音识别选型评分表

> 配套：[选型与评测](./xinli-asr-selection.md)。状态：方案，尚无实测结论。门槛数值、权重、评分锚点和样本计划须根据探索数据与产品容忍度，在正式留出结果可见前冻结，记录在 §6。缺少的数值不视为默认通过。

## 1. 用法

1. 每个“供应商 × 接口/模型/区域 × 分离/佩戴者判定 × 硬件/VAD/分片策略”是一个候选。默认比较完整识别方案；只测转写的组件另表比较，不能凭此选定 xinli 主用或备份。
2. **首轮不运行整理 Agent，A4 暂缓。** 下游评测在任何阶段都不计分：A4 只是短名单的验收门槛（设计 §8）。直接比较转写、关键信息、分离、跨分片佩戴者、漏识/幻觉、时间与边界、工程与成本，形成 2–3 个候选。
3. 每项门槛填“通过 / 不通过 / 证据不足”，首轮 A4 填“阶段暂缓”。失败不进入排名；证据不足只进入待补测列表，不能标为通过。
4. 短名单完成设计 §8.2 的评分器修正后，才运行下游评测、判定 A4；分数仍用 §3 的同一组权重，在真人留出数据上重算。
5. 每格记录原始值、分子/分母、区间、得分和数据类别（合成/重录/真人）。最终效果与身份安全用真人留出数据，合成/重录作辅助。
6. 总分为 `Σ 权重 × 得分 / 5`，满分 100。**缺任何本阶段必填项不算正式总分；不得按已填权重归一化。** B13 和可选他人跨天身份均是诊断，不临时加分。

## 5. 决策规则

1. 首轮仅形成 2–3 个候选：硬门槛通过者按首轮分数与原始指标排序；证据不足者另列补测，不冒充通过者。只测转写的组件结论不能用于上线。
2. 真人留出绝对效果决定最终效果分。合成/重录排名不同不自动淘汰；调查差异后以真人为准。
3. 短名单先完成下游评分器修正，再判定 A4，并按同一组权重在真人留出数据上重算分数。全部门槛通过且证据齐全才可选定。A4 不通过时，用设计 §8.4 的受影响承诺与人工参考臂配对比较，区分识别造成的增量损失与模型错误、波动或评分器问题；确认是识别造成的，才在新一轮修订标注或门槛。
4. 总分差不超过预先约定的 5 分、且关键效果差异的区间已落入业务容忍范围时，优先完整月成本较低者；否则补测，不把“差异不显著”当等效。
5. 备份与主用使用同样的安全、数据、效果和容量门槛，确认声纹/热词迁移及切换删除流程；不能自动把第二名当合格备份。
